# VPN Manager (WireGuard)

Дипломный проект: локальная система управления VPN-инфраструктурой предприятия на базе WireGuard.

## Возможности
- Dashboard: узлы, клиенты, активные соединения, события.
- Управление топологией: подсети, связи (офис/филиалы/сотрудники).
- Генерация WireGuard-конфигов (server/client) и QR для клиента.
- DEMO/REAL режимы работы.
- Мониторинг туннелей и история snapshot.
- Backup/restore конфигов.
- Журнал аудита (файл + БД).
- Диагностика окружения.
- Простая локальная авторизация admin.

## Запуск в PyCharm
1. Откройте папку `vpn_manager` как проект.
2. Создайте виртуальное окружение Python 3.11+.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте `.env` на основе `.env.example`.
5. Запустите `main.py`.
6. Откройте `http://127.0.0.1:8000`.

Логин по умолчанию:
- username: `admin`
- password: `admin123`

## Режимы
- `APP_MODE=auto` — автоматически: Linux+wg => REAL, иначе DEMO.
- `APP_MODE=demo` — принудительный DEMO.
- `APP_MODE=real` — принудительный REAL (рекомендуется Linux с установленным WireGuard).

## Инициализация и seed
Выполняется автоматически при старте. При необходимости:
